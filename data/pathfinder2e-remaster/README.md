# Базовые правила PF2e Remaster

Локальный текстовый справочник на английском языке из **Player Core (2023)**
и раздела Difficulty Classes из **GM Core (2023)**. Снимок загружен
из Archives of Nethys **28 октября 2026 года**, с доступными там исправлениями.
Редакция: Pathfinder Second Edition Remaster. Лицензия текстов: **ORC**.

Это справочник базовой механики. Полные каталоги происхождений, классов,
черт, отдельных заклинаний, предметов и существ находятся за пределами снимка.
Ссылки на такие материалы ведут к исходному сайту и требуют интернета.
Приложение пока не загружает этот справочник в контекст ИИ автоматически.

## Происхождение и преобразование

[sources.json](sources.json) содержит для каждого файла исходный URL,
книгу, страницы, дату получения, размер, SHA-256 исходного HTML и результата.
Для удалённых блоков записаны тип и хеш текста. Там же указан исходный адрес
и контрольная сумма неизменённой полной лицензии.

Текст выгружен из разделов правил и навыков; навигация, скрипты, реклама,
интерактивные блоки сайта и изображения удалены. Таблицы преобразованы
в Markdown; объединённые ячейки развёрнуты с сохранением значений.
Текстовые обозначения стоимости действий сохранены. URL сделаны абсолютными.

Из копии удалены раздел с игровыми допущениями мира, образец персонажа,
смешанные комплекты снаряжения из других книг, а также абзацы и примеры
с именами персонажей, божеств, организаций и мест сеттинга. Удаления обозначены
в тексте. Упоминания названия игры в основном тексте заменены маркером
`[game name omitted]`; названия изданий сохранены для указания источников.
Редакторские ссылки на дополнительные материалы из других книг исключены.
Перевод, пересказ и новые игровые механики в этот снимок не добавлялись.

Перед обновлением требуется проверять новый текст и уведомления источников:
контрольные суммы фиксируют именно этот снимок, а не изменяемую версию сайта.
