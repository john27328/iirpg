## Бесплатная модель

Живой opt-in прогон `release_tests/live_action_plans.py --live --case all`
прошёл четыре пути с `nvidia/nemotron-3.5-super-vl:free`:

1. Вопрос о книге без перемещения → убрать оружие/щит → перейти → подобрать
   и держать лом → выломать сундук своим броском → взять → вернуть книгу.
2. Другой сценарий: вопрос о калитке → инструменты → открыть проход →
   перейти через промежуточное место → взять рожок → передать сторожу.
3. Познакомиться → собственный бросок отношения → просьба → собственный
   бросок согласия → совместный переход → подготовка Aid → вопрос о том,
   чья Атлетика используется → отмена ожидающей попытки.
4. Вопрос вместо действия → отсутствие Телепортации без подмены ходьбой →
   угроза → критический провал без согласия → смена темы → извинение и
   уточнение адресата → новая проверка отношения.

Броски игрока в живом прогоне детерминированы для проверки переходов;
все четыре степени и другие значения отдельно проверяются офлайн. Для
неоднозначных социальных реплик скрипт допускает одну содержательную реплику
игрока с уточнением; отсутствие дальнейшего прогресса считается ошибкой.
Само уточнение не должно менять место, владение, результат или ожидающий бросок.

Это проверка конкретных путей, не гарантия понимания любого текста. При
предыдущих прогонах модель теряла часть составного намерения, путала ссылки
мира с инвентарными ID и повторяла старый ответ на извинение. Внесены общие
исправления протокола и ссылок; ошибки интерпретации всё ещё возможны. Если
модель сомневается, игрок продолжает тот же чат; полного живого мастера этот
ограниченный исполнитель не заменяет.

Трассы и отчёты находятся только в `.local/action-eval-*.sqlite3`/`.json`.
Проверки не читают пользовательские разговоры и не меняют их сохранения.
