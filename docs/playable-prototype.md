# Играбельный боевой прототип

Откройте `/battle`, создайте учебного героя (или выберите существующих),
выберите заготовку и начните бой. Карта, инициатива, доступные действия,
состояния и журнал находятся на одной странице.

Клетка пола предлагает перемещение; клетка противника — доступные действия
против него. Кнопка проходит проверку бесплатного ИИ и исполняется без второго
подтверждения. После своих действий завершите ход: включённая автоматическая
очередь разыграет противников и вернёт управление вашей группе. Переключатель
позволяет приостановить очередь. Скрытая вкладка не запускает новые запросы.
Ошибки, отсутствие ключа или лимит запросов останавливают автоматическую игру;
есть ручной шаг и обычная тактика. Платная модель автоматически не подключается.

Свободный текст создаёт обсуждаемое намерение. Его можно уточнять следующими
сообщениями; только окончательное предложение подтверждается игроком. После
завершения боя можно выбрать другую заготовку и сыграть снова. Исходные ОЗ
листов сохраняются, бой использует учебную копию характеристик.

Основа механик — сохранённые документы:
- `data/pathfinder2e-remaster/rules/playing-the-game.md`: инициатива, три действия,
  степени успеха, штраф повторных атак, завершение хода;
- `data/pathfinder2e-remaster/skills/intimidation.md`: Деморализация;
- `data/pathfinder2e-remaster/rules/conditions.md`: испуг;
- `data/pathfinder2e-remaster/skills/athletics.md`: проверки Атлетики.

Конкретные числа задают конфиги `src/iirpg/rules/`; лицензии и атрибуция остаются
рядом с правилами. Учебный герой — авторский набор характеристик для проверки
боя, не полная сборка класса. Карты, противники и условия сдачи — учебные примеры.
Прототип не реализует весь Pathfinder: отсутствуют полный каталог классов и
заклинаний, площадные эффекты, полный набор реакций и полноценная кампания.

Проверка реального бесплатного ИИ отдельно от обычных тестов:

```bash
PYTHONPATH=src python3 release_tests/live_ai_combat.py --group duel --max-ai-requests 20 --report .local/prototype-live.json
```

Прогон создаёт отдельную комнату. Ключи и отчёты в `.local/` не публикуются.
