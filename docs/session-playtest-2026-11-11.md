# Проверка игровой сессии, 11 ноября 2026

Живой бесплатный мастер: `nvidia/nemotron-3.5-super-vl:free`. Основную комнату
игрока не изменяли. Полные ответы и состояния: локальный отчёт
`.local/gm-playthroughs-after-fixes.json` (не публикуется).

Первое прохождение выявило:

- Мастер описал выход во двор через narrate; состояние осталось в зале.
- Вход в зал автоматически возвращал книгу, хотя герой явно оставлял её себе.
- Ветка нападения прервалась из-за неверного формата ответа.
- В описании работы с сундуком появлялась неуместная ссылка на «агрессию».

Исправления: строгая схема ответа, `location_after` с проверкой соседства,
явная команда `return_book`, актуальный владелец книги и инвентарь в контексте,
уточнённая инструкция о последствиях проверок. В отладке теперь сохраняется
и ответ модели, не прошедший проверку формата.

Повторный прогон: 21 реплика игрока, 3 контролируемых броска, 24 обращения к
бесплатной модели, сообщённая провайдером стоимость 0. Проверены:

| Эпизод | Результат |
| --- | --- |
| Знакомство, уход и возвращение | Конюх сохранил имя и предыдущий разговор; перемещения совпали с состоянием |
| Дубина как рычаг, получение и изучение книги | Проверка предложена игроку; критический успех дал книгу |
| Возврат в зал с книгой при себе | Задание осталось незавершённым |
| Явная передача книги | Задание завершено, владелец — хозяйка |
| Разговор после завершения | Хозяйка помнит возвращённую книгу |
| Неудачная угроза | Отказ отвечать, настороженность, без подмены провала успехом |
| Успешное нападение | Немедленная реакция; при возвращении NPC помнит нападение |
| Неподдерживаемая магия | Объяснение ограничения, герой остался в зале |

Повтор броска проверялся после каждой карточки: результат и состояние не менялись.
Автоматические проверки сверяли помещения и завершение задания; качество и
непротиворечивость ответов дополнительно проверены чтением диалогов. Это
ограниченный набор примеров, а не гарантия качества для любого текста.
Рукопашная проверка — упрощение учебной сессии, не полная боевая система PF2e.
